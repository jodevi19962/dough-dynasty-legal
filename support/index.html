Dough Dynasty Support

Last updated: 24 October 2026.

Dough Dynasty is available as a free offline pizza tycoon from Jodevi Games. If something goes wrong, we want to help.

Contact

Email jonathandevisser1996@gmail.com. Please include your device model, Android version, and a short description of what happened.

Typical issues

  • Save / progress. Progress is stored only on this device. If a save will not load, try closing the app fully and opening it again. Uninstalling the app or clearing app data deletes local progress.
  • Language. Dutch, English, and German are available in Settings. Change the language there if the text is not in the language you expect.
  • Delete progress. Open Settings in the game and use the delete option. This cannot be undone. It removes local gameplay progress and app preferences on this device.
